## Commerce is becoming programmable
First came online checkout. Then APIs. Now agents that complete the whole loop — intent → design → price → order → fulfilment — without a human clicking "buy."

## What "agent commerce" means in practice
- An agent reads a need ("we need launch swag").
- It generates and publishes the designs.
- It prices them and places the order.
- It tracks fulfilment and reports back.

## Why Desmake is built for it
- **MCP-first:** a scoped key exposes 14 tools — search, generate, publish, order, track.
- **On-demand:** no inventory to misforecast; agents order exactly what's needed.
- **Auditable:** per-key scopes and metering mean you can trust an agent with real fulfilment.

## The risk and the guardrail
Giving agents spending power is real. Desmake's answer is scoped keys + a full audit trail, so an agent can sell and fulfil without holding the keys to the kingdom.
